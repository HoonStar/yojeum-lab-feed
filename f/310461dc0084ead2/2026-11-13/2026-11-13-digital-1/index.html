오늘은 60대 부모님 윈도우10 노트북 보안 업데이트 연장 이야기를 해볼게요.

작년부터 "2026년 10월이면 보안 업데이트가 끊긴다"는 안내가 많았거든요.

그런데 마이크로소프트가 소비자용 확장 보안 업데이트(ESU) 기간을 2027년 10월 12일까지 늘렸어요.

부모님 댁 노트북이 아직 윈도우10이라면 이번 주말에 10분만 같이 봐 드리면 됩니다.

**핵심만 먼저: 윈도우11로 갈 수 있는 노트북이면 무료로 업그레이드하고, 안 되면 설정 > 업데이트 및 보안 > Windows 업데이트에서 'ESU 지금 등록'을 누르세요. 설정 동기화를 켜면 비용 없이 2027년 10월 12일까지 보안 업데이트를 받아요.**

1. 지난달 끝난다던 업데이트, 왜 아직 오나요?

날짜가 두 개라서 헷갈리는 거예요.

기본 지원은 마이크로소프트 안내 기준 2025년 10월 14일에 이미 끝났습니다.

그 뒤로는 ESU에 등록한 PC만 보안 업데이트를 받아요.

이 ESU가 원래 2026년 10월 13일까지로 알려졌는데, 마이크로소프트 ESU 안내 페이지가 2027년 10월 12일로 바뀌었어요.

오늘(11월 13일)부터 세면 333일 남은 셈이죠.

이미 등록한 PC는 따로 할 일이 없어요. 같은 날짜까지 자동으로 이어집니다.

⚠️ 업데이트가 끊겨도 노트북은 그대로 켜져요. 그래서 끊긴 줄 모르고 쓰시는 경우가 많더라고요.

2. 부모님 노트북, 윈도우11로 갈 수 있을까?

제일 깔끔한 길은 윈도우11 무료 업그레이드예요.

사양을 충족하면 Windows 업데이트 화면에 업그레이드 안내가 뜹니다.

마이크로소프트가 밝힌 최소 사양은 아래 표와 같아요.

직접 따지기 어렵다면 'PC 상태 검사' 앱을 깔아 버튼 하나로 확인하세요.

항목최소 사양
프로세서64비트 1GHz 이상, 2코어 이상
메모리(RAM)4GB 이상
저장공간64GB 이상
보안TPM 2.0, UEFI 보안 부팅

💡 산 지 오래된 노트북은 프로세서 조건에서 걸리는 경우가 많아요. 그럴 땐 바로 3번으로 가세요.

3. 60대 부모님 윈도우10 노트북 ESU 등록 5단계

1단계: 시작 버튼 옆 검색창에 winver를 입력해 버전이 22H2인지 봅니다.

2단계: 설정 > 업데이트 및 보안 > Windows 업데이트에서 대기 중인 업데이트를 모두 설치해요.

3단계: 마이크로소프트 계정으로 로그인했는지, 그 계정이 관리자인지 확인합니다. 자녀 계정이면 안 돼요.

4단계: 같은 Windows 업데이트 화면에서 확장 보안 업데이트 안내를 찾습니다.

5단계: '지금 등록'을 누르고 등록 방법을 고르면 끝이에요.

부모님이 비밀번호 없이 로컬 계정만 쓰고 계셨다면 3단계에서 시간이 좀 걸려요(처음 보면 여기서 많이들 멈추세요).

4. 무료·포인트·유료, 어떤 방법이 맞을까?

마이크로소프트 안내 기준 등록 방법은 세 가지예요.

어떤 방법을 골라도 보안 업데이트를 받는 기간은 같아요.

그래서 저는 대부분의 부모님 댁에는 설정 동기화(무료)를 추천해요.

방법비용이런 분께

1회 구매30달러(세금 별도)동기화를 원치 않는 경우

📊 계산해 보면 30달러를 333일로 나눠도 하루 약 0.09달러예요. 그래도 무료 길이 있으니 먼저 동기화부터 시도해 보세요.

5. 등록 뒤 부모님 댁에서 챙길 것

등록이 끝나면 Windows 업데이트 화면에서 등록 상태 문구를 한 번 확인하세요.

다음 달 정기 보안 업데이트가 기록에 남는지 보면 확실해요.

사진과 문서는 이참에 외장 저장장치나 클라우드에 한 벌 더 두는 게 마음 편합니다.

2027년 10월 12일 이후에는 연장 소식이 또 있을지 알 수 없어요.

그래서 내년 여름쯤 새 노트북을 볼지 미리 이야기해 두는 걸 권해요.

자주 묻는 질문

Q. 등록 안 하면 노트북이 꺼지나요?
A. 아니요. 계속 켜지고 쓸 수 있어요. 다만 새 보안 패치를 받지 못해 인터넷뱅킹·메일을 쓰기엔 불안해집니다.

Q. 윈도우10 노트북이 두 대면 따로 결제해야 하나요?
A. 같은 마이크로소프트 계정이라면 Windows 업데이트 화면의 '디바이스 추가'로 다른 PC도 등록할 수 있어요.

Q. 회사에서 받은 노트북도 되나요?
A. 회사 도메인·관리 프로그램(MDM)에 묶인 PC는 이 소비자용 등록 대상이 아니에요. 회사 전산 담당자에게 물어보세요.
